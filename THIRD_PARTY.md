# Third-party artwork and design references

The Chessnut SVG chess pieces in pieces.js are by Alexis Luengas, distributed under Apache License 2.0. Original project: https://github.com/LexLuengas/chessnut-pieces . Files retrieved from https://github.com/lichess-org/lila/tree/master/public/piece/chessnut . The SVG artwork is unmodified; the application adds a CSS class and accessibility attributes at render time. Full license: licenses/chessnut.txt.

The layout was independently implemented after inspecting Lichess's round layout and move-list source at https://github.com/lichess-org/lila/tree/master/ui/round/css and Chess.com's computer-play navigation at https://www.chess.com/play/computer . No Lichess application code or Chess.com artwork is bundled. Rookwise is an independent app.
